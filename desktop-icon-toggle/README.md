# 🐱 桌面图标开关

想完整看看壁纸，或在共享屏幕前把桌面收拾干净？点一下奶牛猫，桌面图标就收起来。再点一下，图标原位回来。

**[下载 Windows 安装包](https://github.com/zhailan7796-boop/wishelp/releases/download/desktop-icon-toggle-v1.1.0/DesktopIconToggle-Setup-1.1.0.msi)** · Windows 10 22H2 / Windows 11

## 安装后怎么用

1. 双击下载的 MSI，点击「安装」。安装范围是当前 Windows 账户。
2. 按 **Win**，搜索并打开 **桌面图标开关**。每打开一次，就切换一次。

| 想做什么 | 从哪里打开 |
| --- | --- |
| 收起图标，或把它们显示回来 | 开始菜单 → **桌面图标开关** |
| 直接显示图标 | 开始菜单 → **恢复桌面图标** |
| 用 Windows 自带的方法恢复 | 右键桌面空白处 → **查看** → **显示桌面图标** |

## 安装和隐私

- 使用 Windows 自带的 .NET Framework。双击安装包即可安装，支持离线安装和使用。
- 只切换 Windows 的桌面图标显示状态。桌面文件、快捷方式和布局都保留在原处。
- 程序运行后即退出。无需管理员权限，无后台服务、开机启动、联网或桌面诊断日志。
- 可在 Windows 的应用设置中搜索 **桌面图标开关** 并卸载。桌面图标需要恢复时，仍可使用桌面右键菜单。
