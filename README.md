# 随屏 · wishelp

随屏是一款 Windows 11 x64 多屏工具。从哪块屏幕的任务栏打开或恢复应用，随屏就尝试让窗口在那块屏幕显示。

## 下载与使用

1. 打开 [Releases](https://github.com/zhailan7796-boop/wishelp/releases)，在 Assets 中下载 `TaskbarFollow-0.3.1-portable.zip`。
2. 解压整个 ZIP，双击 `Start.exe`。随包附带运行时，无需另外安装 AutoHotkey。
3. 等状态显示「运行中」，从目标屏幕的任务栏打开或恢复应用。

按 `Ctrl+Alt+F12` 暂停或启用跟随。收起窗口后程序继续在托盘运行，点「退出程序」即可停止。

兼容范围、配置、项目源码和许可证见 ZIP 内的文件。
